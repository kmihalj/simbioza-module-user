# Odgođena integracija Confluence sitea

`confluence-site` čuva neobjavljenu izričitu administratorsku izradu osobnog
područja neaktivnog vlasnika, regresijske testove, integracijsku dokumentaciju i
povezanu QA konfiguraciju. Čuvanje ove razvojne snimke ne mijenja automatsku
izradu nakon prijave ni Auth postavke.

Uvoz cijelog sitea odgođen je 17. listopada 2026. Radna kopija vraća se na
objavljeni `main` (`2df6deb`, 0.3.0). Ova grana nije izdanje; oznake verzija
kandidata treba provjeriti prije buduće objave. Nastaviti uz odgovarajuće grane
importera, Calendara i Simbioze, bez spajanja samo radi isporuke postojećeg uvoza
jednog područja. Auth i Framework su izvan opsega.
